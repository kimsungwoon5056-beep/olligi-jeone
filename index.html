        시연 영상
        
    
    
        첫 화면 시연, 택배 송장 분석, 테이프로 저장, 단톡 캡처를 가족방 기준으로 다시 판단, 인터넷을 끊은 상태에서 지갑 사진 분석까지 담았어요. 영상 속 정보는 모두 가짜예요.
        
  
        

  
        
    
        내 사진을 넣어도 안전한 이유
        
    
          
      
        • 사진이 이 기기 밖으로 나가지 않아요글자 읽기·얼굴 찾기·장면 판단 AI가 모두 이 브라우저 안에서 돌아요. 사진을 서버에 올리는 코드가 아예 없어요.
          • 
      
        • 보내고 싶어도 못 보내게 막았어요AI 모델과 글꼴까지 모두 이 사이트 안에 있어요. 브라우저 보안 규칙(CSP)으로 이 사이트 말고는 어디에도 연결하지 못하게 정해 두었어요. 이 시연 사이트(GitHub Pages)는 파일만 보여 주는 곳이라 사진을 받아 저장할 수도 없어요.
          • 
      
        • 사진과 결과를 기억하지 않아요쿠키와 방문 분석 도구를 쓰지 않아요. 사진은 메모리에만 있다가 탭을 닫으면 사라져요. 브라우저에 남는 것은 다음에 빨리 열리도록 보관하는 AI 모델 파일뿐이에요.
          • 
      
        • 저장한 사진은 깨끗해요가린 사진은 새로 그려서 저장해요. 위치·기기·촬영 시각 정보가 남지 않고, 저장한 파일을 다시 열어 정말 지워졌는지 확인해 보여 줘요.
          • 
      
        • 누구나 코드를 볼 수 있어요전체 코드가 GitHub에 공개돼 있어요.
